## 真实服务

环境：Go 1.26.0、Node 22.16.0、Python 3.11.2、PostgreSQL 17、Redis 7、Qdrant 1.18.1、Chromium 153.0.8010.12。Node 实测版本与仓库 CI 的 Node 24 不同。模型使用 DeepSeek `deepseek-v4-flash`；没有用模型 mock 替代真实出题或 Agent 调用。

真实 API **36 项通过**，15 项观测单独计数，覆盖：

- 默认关闭、显式开启、概览、稳定推荐、阅读只改变熟悉度、Wiki overlay。
- 三题异步生成、未作答时不泄露答案、引文来自有效来源。
- 固定选择第一个选项，由服务端判分；BKT 更新、重放幂等、冲突返回 409。
- 另一租户读取和提交答案返回 404。
- 内置学习 Agent 实际调用概览、推荐、Wiki 阅读和测验准备，工具结果只保存卡片引用。
- 关闭后仍可导出和清除；非空记录清空、重复清空幂等、另一账号历史保留。

最终提交重建并重启后再次执行 API 验收，36 项仍通过，第一账号已有 3 次答案、1 份题集未丢失。
